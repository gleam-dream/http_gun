# Local validation and operational evidence

## Package gates

```sh
./dev/env sh dev/gate fast
./dev/env sh dev/gate full
sh dev/matrix
```

- `dev/env` enters this repository's pinned Nix shell. `dev/gate` builds an isolated validation copy unless already inside that gate. Normal gates do not consume sibling working copies.
- Fast checks formatting, Gleam check/build/tests, native warnings and ownership/dependency boundaries. Full adds stdlib edge versions, ordinary/async consumers, real nghttpd HTTP/2, shared batch budgets, recording and load observations.
- The runtime matrix qualifies each selected shell in isolation. Measurements report their actual runtime, workload and capacity. Passing tests establish their named observations rather than a whole-stack memory bound.

## CI and validation evidence

- `dev/gate` remains the canonical runtime entry point. Its outer invocation checks the original Git tree with `nix flake check --print-build-logs` and runs gate controls before creating an isolated package copy. Nix entry points use Git flakes; ignored local credential files are not copied into Nix source snapshots.
- The Nix checks enforce canonical Gleam/Nix/Elixir/Markdown/YAML/Python formatting and authored-tooling lint. The locked nixpkgs input pins actionlint, ShellCheck and Ruff; actionlint also checks workflow shell commands. ShellCheck checks the authored shell adapters and `.envrc`, while Ruff uses only syntax and undefined/unused-name rules (E9/F) on authored `dev/**/*.py`.
- Formatting excludes generated build/render/PDF output, retained `docs/history` evidence, frozen `dev/dependencies` bytes and disposable `dev/results`. Compiler-negative fixtures stay in temporary consumer copies; no invalid fixture is admitted as production source.
- `dev/check_native.py` independently compiles authored Erlang with `erlc -Werror`, dependency include paths and generated dependency BEAM paths. It checks root production/test modules and the separate ordinary/async consumer FFI, including copied local servers. Gleam's warning flag does not reject native Erlang warnings; a valid native module and an intended unused-variable rejection test qualify this gate separately.
- `dev/check_results.py` rejects missing, empty, failed, skipped or ambiguous successful test summaries. It requires all eleven distinct load workloads and preserves their H1/H2 connection and large-byte assertions. Controls also reject malformed JSON, duplicate/missing workloads and stale consumer dependency resolution. Native fault tests retain their expected error reports without a blanket runtime-log warning filter. A timeout control proves isolated gate descendants stop before workspace cleanup; ordinary failure codes and diagnostics are retained.
- Full qualification tests the advertised stdlib lower bound and the selected current version. Each version receives a separate public consumer build and complete fast package suite. The disposable test copy resolves stdlib with a compatible Gleeunit inside the existing dev-dependency range; the product manifest remains the qualification authority. Gun/Cowlib versions selected in the root qualification copy are pinned into both ordinary/async consumer copies and stdlib consumers; their resolved manifests are checked against the root selection and retained.
- Each gate run replaces generated `build/evidence` so a failed run cannot export an old success receipt. `build/evidence/logs` retains commands and raw per-check logs; benchmark JSON stays separate from compiler diagnostics. `build/evidence/manifests` retains the root, ordinary, async and stdlib consumer/package manifests; each stdlib fast suite has its own log directory. `summary.json` records the isolated profile, selected dependencies, elapsed time, outcome and exit code, including failed runs.
- The `CI` workflow runs six full-gate lanes: OTP 27, OTP 28 and the default OTP 29 shell, each with committed minimum and newest admitted Gun/Cowlib patches. The design job remains separate. The final `CI` job accepts only successful runtime-matrix and design results; failures, cancellations and skipped mandatory jobs cannot pass it.
- Every push, pull request and manual dispatch runs required CI with pinned actions, read-only repository permission, superseded-run cancellation and bounded job times. Raw runtime and design evidence uploads on failures and is retained for 14 days; missing expected evidence fails artifact collection.
- The separate extended workflow runs weekly or manually: a ten-minute local nghttpd soak, native ARM64 full qualification and the pinned public comparison harness. It retains results for 30 days and has its own final status. The established batch scaling guard remains `5000 requests < 15 × 500-request median + 50 ms`; measurements add no absolute latency SLA.

## Public consumers and downstream selection

- [Ordinary consumer](../examples/ordinary/src/http_gun_consumer.gleam) compiles as its own package and demonstrates common calls, advanced views, caller error types, observation routes and record/replay.
- [Async recipe](../examples/async/README.md) owns bounded application jobs, worker lifetime, synchronous sinks and cancellation. [Comparison harness](../examples/comparison/README.md) keeps benchmark differences explicit.
- `dev/consumers` includes public-import and opaque-capability checks. `dev/check_downstream.py` performs explicitly selected isolated LLM Wire qualification and records source identity. The selected current runner writes directly to a fresh `local-http` receipt directory. Source hashing and copying exclude credential names before file reads. Inspect that command's arguments before use; it is deliberately outside the ordinary gate.
- Historical archived consumers prove only their recorded revisions. Current downstream compatibility requires selecting the current source and checking originals remain unchanged. No normal gate should silently modify a sibling checkout.

## Local fixtures and evidence

- Tests use local Erlang HTTP/H2/TLS servers and [test certificates](../test/fixtures/README.md). `dev/ip-fixture` generates the IP-SAN case. Loopback access is explicitly enabled by each local test client.
- `dev/nghttpd.py` uses the development nghttpd package for real peer-capacity and trailer checks. Local interop owns no provider semantics or public Internet requirement.
- `build/evidence` contains current runtime outputs. `docs/history/evidence` preserves raw source/hash/receipt/log inputs from earlier qualification, including Dream comparison, Sinal source selection and destination/Warden scenarios. These retained paths are evidence storage; they do not carry a competing design contract or current completion diary.
- `NOTICE`, dependency licenses and fixture attribution remain authoritative for source reuse. Git retains retired prose reports; [ADRs](adr/0001-gleam-owns-exchange-state.md) record material decisions.

## Recording operation

- Stop the HTTP client separately from finishing or aborting capture. A finish wait timeout does not abort capture. Another finish can observe the eventual result; an abort cannot remove an already published file.
- Staging directories use the destination's `.http-gun-` suffix and contain sensitive exact data outside the selected redaction. Cleanup is attempted on failures and recorder loss. The current primitive ignores removal failures and can leave data while a writer is blocked; inspect and remove abandoned staging data after its owners have exited.
- Successful publication guarantees a complete visible fixture on the destination filesystem. It does not guarantee survival after power loss. [The unresolved cleanup decision](adr/0010-consolidate-design-and-expose-cleanup-gap.md) records the stronger public-promise tension.
- `dev/convert_cassette.py` is an explicit offline schema-1-to-2 conversion tool. Runtime playback retains one current decoder and never migrates or rerecords automatically.
